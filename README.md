# BrightSmile Dental Appointment System

BrightSmile is a modern dental appointment web application designed to make booking dental services simple, clear, and convenient for patients.

The system allows users to select a dental service, choose a dentist, check available dates and schedules, and book an appointment through an easy-to-use interface.

## Features

* Dental service selection
* Dentist selection based on specialty
* Dentist availability checking
* Appointment date and time selection
* Calendar with appointment availability
* Suggested alternative dates when a schedule is unavailable
* Patient appointment information
* Appointment confirmation
* Responsive design
* Clean and user-friendly interface

## Technologies Used

* React
* TypeScript
* Tailwind CSS
* shadcn/ui
* Lucide Icons
* Vite

## Project Goal

The goal of BrightSmile is to create a simple and user-friendly dental appointment experience while making it easier for patients to find suitable dentists and available schedules.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/brightsmile-dental-appointment.git
```

Navigate to the project:

```bash
cd brightsmile-dental-appointment
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
